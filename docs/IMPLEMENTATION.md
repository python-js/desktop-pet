## 开发与验证命令

在 desktop-pet 目录执行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m desktop_pet
```

无 PyQt5 的环境仍可运行纯标准库核心测试。Qt 无屏幕冒烟测试需显式设置 `QT_QPA_PLATFORM=offscreen`，不能代替真实通知/透明窗口验收。单独记录实际测试结果于 `docs/VALIDATION.md`。

## 风险与决策

1. 先做原生 Qt 垂直切片，不复制旧单体 UI。若后续聊天富文本/多端成为主要需求，再以核心接口迁移展示层。
2. 0.4 默认流式，也支持非流式；完整结果才生成草稿。停止为协作取消，网络阻塞释放前不能发送下一个请求；不承诺停止服务端计费。
3. 应用完全退出或关机不提醒；后台服务、唤醒和手机联动需要另立范围。
4. 图片上传与图片生成是不同功能，本阶段只完成上传与基础互动。
5. API 真实联调需要用户提供自己的配置，不扫描旧项目密钥、不内置开发者密钥。
