# Windows 设置（0.6）

## 安全记住密钥

默认仅将 API Key 保存在当前进程内。勾选“安全记住 API Key”并保存模型设置后，使用 Windows DPAPI 的当前用户范围加密，禁用系统交互提示；密文写入数据目录 `api-key.dpapi`。`settings.json` 仅保存服务地址、模型等非密钥字段和 remember_key 开关，不存 API Key。

密文包包含服务地址和密钥，恢复时必须与当前配置的服务地址完全匹配。自动恢复的密钥在编辑服务地址后清空；程序化更改地址后未重新输入密钥也会被保存校验阻止。用户手动输入的新密钥则按用户选择的服务发送。

取消勾选后保存会删除应用当前密钥文件，当前运行仍可使用输入的密钥。直接取消勾选而未保存不改变持久化数据。不支持安全存储的平台禁用开关，不提供明文回退。解密失败显示提示并保留原文件，用户可重新输入，或关闭记住后保存以移除该文件。

密文使用临时文件写入后原子替换；加密失败不覆盖原文件。配置JSON与密文属于两个独立文件，不能提供跨文件事务；若第二步配置保存失败，应按提示重新保存。地址匹配检查会避免错误配置自动带出其他服务的密钥。

这不是 Windows 凭据管理器条目，而是 DPAPI 加密文件。它不抵御当前用户权限下的恶意程序读取，也不保证迁移到其他电脑或用户后能恢复。用户数据备份可以保留文件，但应准备重新输入密钥。macOS Keychain 尚未实现。

## 开机启动

开机启动开关与模型保存分开：仅点击“应用启动设置”才写入或删除当前用户注册表：

`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `DesktopPet` 值。

不修改系统全局启动项、不需要应用主动申请管理员权限、不修改其他应用的值。若系统策略拒绝则显示错误。

启动命令使用当前Python环境和绝对路径 `launch.py --background`，通过 Windows 参数转义处理空格和中文；优先使用同目录的 pythonw.exe 避免控制台。启动路径超过260字符或文件缺失时拒绝启用。应用默认显示宠物，主窗口收起到托盘；若没有系统托盘则显示主窗口，避免不可见进程。

移动应用文件夹或删除/更换Python环境后，需要重新应用启动设置。源码原型的启动方式不等同于稳定安装包。取消勾选并应用即可删除本应用的启动值。

## 模块与验证

- `secure_storage.py`：DPAPI调用、密文格式、地址匹配和文件管理。
- `startup.py`：当前用户启动项与命令构建。
- `ui/settings.py`：设置展示与显式保存，作为主窗口的独立设置模块。
- `launch.py`：不依赖当前工作目录的入口。

40项测试通过；密钥文件测试使用明确的测试加密器和虚构密钥，启动项测试使用内存注册表替身。Qt集成测试验证记住、重新打开后恢复、地址变更校验、关闭记住、配置不落明文，以及仅显式按钮应用启动设置。

原生DPAPI探测仅使用内存中的合成字符串，当前执行环境返回0x2，未完成真实加解密验证；未据此推断用户桌面环境一定失败。未写入真实启动项，也未验证真实登录自启。需要在正常用户桌面会话中完成这些验收；失败时保留仅当前运行模式。
